# LCA Feature Update

Added:
- Message reactions
- Reply to messages
- Friend-only typing indicators
- Online status (existing, preserved)
- @mentions highlighting
- GIF sending by direct GIF URL
- Message bookmarks
- Dark/light theme toggle
- Message search

Deployment:
- Replace `index.html`, `server.js`, `package.json`, and `README.md` in your existing GitHub repository.
- IMPORTANT: keep your existing `data.json`. Do not replace it with an older/empty data file, so existing accounts, servers, and messages remain.
